# Undangan Digital

Undangan web ini dapat dipublikasikan secara publik melalui GitHub Pages sehingga bisa dibuka dari HP mana pun.

Langkah paling mudah:
1. Upload semua file ini ke GitHub repository.
2. Buka tab Settings > Pages.
3. Aktifkan GitHub Pages dari branch `main` atau `master`.
4. Setelah selesai, link publik akan seperti:
   https://<username>.github.io/<repository>/

Contoh link yang siap dipakai:
https://isa-dea.github.io/undangan/
